# La-Plomada-Equipo-53
La Plomada es una plataforma de e-commerce desarrollada con Laravel para la venta de productos de pesca. Permite a los clientes explorar el catálogo, agregar productos al carrito y realizar compras, mientras que los administradores gestionan el inventario, pedidos y usuarios desde un panel dedicado.
El sistema surge de la necesidad de un comercio de artículos de pesca de contar con un canal de venta en línea propio, que le permita ofrecer su catálogo, gestionar el stock y procesar pedidos sin depender de intermediarios. Se trata de un producto independiente, compuesto por un sitio orientado al cliente (catálogo, carrito y compra) y un panel de administración interno, ambos sobre una misma base de datos.
